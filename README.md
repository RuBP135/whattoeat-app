### 欢迎来到WhatToEat2！

这是 WhatToEat 的现代化跨平台重构版本。我们借助 Kotlin Multiplatform 实现了 Android 与 iOS 双端的核心逻辑与底层架构共享。

本app开发初衷是为了解决吃什么的选择困难症，不过根据实际情况来看，即使有了随机的选择，人们依然会犹豫不定。
现在它已不再单纯随机挑选食物，而会加入更多实用功能，欢迎联系维护者投稿更多实用功能！



目前功能

- 随机食物查询
- 实用网站快捷入口
- 网络测速（校内测速网站）
