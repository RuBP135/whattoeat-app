### 欢迎来到WhatToEat2！

这是 WhatToEat 的现代化跨平台重构版本。我们借助 Kotlin Multiplatform 实现了 Android 与 iOS 双端的核心逻辑与底层架构共享。

本 app 开发初衷是为了解决“吃什么”的选择困难。目前主要围绕联网浏览菜品（Dish）、查看评分和评论，以及为菜品评分、发表评论，帮助大家了解菜品、决定吃什么。

随机选择食物作为辅助决策的功能，此外还提供一些实用小工具。欢迎联系维护者投稿更多实用功能！

## 主要功能

- 联网菜品浏览：查看菜品信息、评分和评论
- 评分与评论：为菜品评分、分享用餐体验
- 随机选择：在犹豫吃什么时随机挑选食物
- 别的小功能（可能增加或移除）：实用网站快捷入口、网络测速（校内测速网站）
